# ✨ Why Splity?

Managing shared expenses shouldn't require spreadsheets or endless calculations.

Splity automatically tracks who paid, who owes, and how much needs to be settled, allowing groups to focus on enjoying the moment instead of worrying about money.

Perfect for:

- ✈️ Trips & Vacations
- 🏠 Roommates
- 👨‍👩‍👧 Families
- 🎓 College Friends
- 💼 Office Teams

---

# 🚀 Features

### 👥 Group Management

Create unlimited groups and invite members for different occasions.

### 💸 Smart Expense Tracking

Add, edit, and manage shared expenses with ease.

### ⚖️ Automatic Balance Calculation

No manual calculations. Splity computes balances instantly.

### 📊 Real-Time Updates

Changes sync across devices instantly using Supabase Realtime.

### 📱 QR-based UPI Settlement

Generate QR codes and settle balances quickly using any UPI app.

### 🔐 Secure Authentication

Email authentication powered by Supabase Auth.

### 🌙 Beautiful Responsive UI

Designed for desktop, tablet, and mobile devices with a clean dark interface.

### ⚡ Fast & Modern

Built with performance, scalability, and user experience in mind.

# ⚡ Getting Started

## Clone Repository

```bash
git clone https://github.com/yashbajaj02/Splity.git
```

## Navigate

```bash
cd Splity
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
